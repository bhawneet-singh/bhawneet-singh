## 🚀 Featured Projects

### 🕹️ NES Emulator
> A fully functional Nintendo Entertainment System emulator — running classic NES games entirely in the browser. Built from scratch in JavaScript. No libraries. No shortcuts.

- ⚙️ **Cycle-accurate MOS 6502 CPU** — every opcode, every cycle, from scratch
- 🖥️ **PPU (Picture Processing Unit)** — complete software rasterization engine in a Web Worker, renders via HTML5 Canvas
- 🔊 **APU (Audio Processing Unit)** — authentic NES audio via Web Audio API
- 🐛 **Custom Debugger** — real-time CPU state, memory maps, PPU inspection
- 🌐 **Runs in the browser** — no install, no plugins, just open and play
